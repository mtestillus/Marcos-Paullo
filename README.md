# MP Performance — Site estático

Arquivos incluídos:
- index.html
- styles.css
- script.js
- favicon.svg

Como rodar localmente:
1. Abra `index.html` diretamente no navegador (funciona).
2. Para servir via HTTP (recomendado), execute no terminal:
   - Python 3: `python3 -m http.server 8000`
   - Acesse http://localhost:8000

Deploy rápido:
- GitHub Pages: crie um repositório, faça commit desses arquivos na branch `main` e ative GitHub Pages nas configurações.
- Netlify: arraste e solte a pasta com esses arquivos no painel (drag & drop) ou conecte ao repo.
- Vercel: `vercel` apontando para uma pasta estática.
